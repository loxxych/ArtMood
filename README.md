# ArtMood

ArtMood - iOS-приложение на UIKit, которое подбирает произведения искусства под настроение пользователя. Пользователь проходит короткий квиз, выбирает настроение, цветовую палитру и тип картины, после чего приложение формирует персональную галерею работ.

## Возможности

- Стартовый экран с анимированными декоративными элементами.
- Квиз из нескольких шагов:
  - выбор настроения;
  - выбор цветовой палитры;
  - выбор типа картины.
- Персональная галерея произведений на основе ответов пользователя.
- Алгоритм рекомендаций с подсчетом совпадений по настроению, палитре и типу картины.
- Экран детальной информации о произведении.
- Полноэкранный просмотр изображения картины.
- Добавление работ в избранное.
- Отдельный экран с избранными произведениями.
- Локальное хранение избранного через `UserDefaults`.
- Кастомные UI-компоненты: кнопки, заголовки, карточки, ячейки галереи.
- Локальные изображения картин, SVG-иконки и подключенные шрифты.

## Архитектура

Проект построен вокруг связки `MVVM + Coordinator`.

- `AppCoordinator` управляет навигацией между экранами.
- `ViewController` отвечает за отображение интерфейса и обработку пользовательских действий.
- `ViewModel` хранит состояние экрана и бизнес-логику.
- `ArtworkRecommendationService` подбирает картины по ответам квиза.
- `FavouritesStore` отвечает за сохранение и чтение избранного.
- `ArtworkMockData` содержит локальную коллекцию произведений искусства.

## Логика рекомендаций

Рекомендации строятся на основе трех параметров:

- настроение;
- палитра;
- тип картины.

Каждая картина получает score:

- совпадение по типу картины: `+3`;
- совпадение по настроению: `+3`;
- совпадение по палитре: `+2`.

После этого работы с положительным score сортируются по убыванию релевантности. Если score одинаковый, сортировка идет по названию картины.

## Основные экраны

### Start Screen

Стартовый экран приложения с логотипом, описанием, декоративными изображениями и двумя действиями:

- начать подбор;
- открыть избранное.

### Quiz Screens

Последовательность экранов для сбора предпочтений пользователя:

- `MoodPickViewController` - выбор настроения;
- `PalettePickViewController` - выбор цветовой палитры;
- `TypePickViewController` - выбор типа картины.

### Gallery Screen

Экран с персональной подборкой произведений. Данные загружаются через `GalleryViewModel`, который использует `ArtworkRecommendationService`.

### Artwork Details

Экран детальной информации о картине. Позволяет посмотреть изображение, данные о произведении и добавить работу в избранное.

### Favourites Screen

Экран избранных работ. Список формируется на основе id, сохраненных в `UserDefaults`.

## Данные

В проекте используется локальная коллекция картин из `ArtworkMockData`.

Каждое произведение содержит:

- `id`;
- название;
- автора;
- год;
- имя изображения в ассетах;
- список настроений;
- список палитр;
- тип картины.

## Хранение избранного

Избранные произведения сохраняются локально через `FavouritesStore`.

Для хранения используется массив id картин в `UserDefaults` по ключу:

```swift
favourite_artwork_ids
```

## Запуск проекта

1. Открыть `ArtMood.xcodeproj` в Xcode.
2. Выбрать нужный симулятор iPhone.
3. Запустить проект через `Run`.

## Особенности реализации

- Весь интерфейс написан кодом без storyboard для основных экранов.
- Навигационная логика вынесена в координатор.
- Для переиспользуемых элементов интерфейса созданы отдельные компоненты.
- Тексты с разным начертанием собираются через `NSAttributedString`.
- В проект добавлены локальные изображения произведений искусства и кастомные шрифты `Instrument Sans`.
